# Typora语法讲解

## 一、基本语法讲解

### 1、加粗

（ 双*包含/双_包含 ）

**这是一段试验文本**

__这是一段试验文本__

### 2、斜体

（ 单*包含/单_包含 ）

*这是一段试验文本*

_这是一段试验文本_

### 3、删除线

（ 双~包含 ）

~~这是一段试验文本~~

### 4、分割线

（ 3↑* ）

***

### 5、分级标题

（ N#+空格 ）

\#

\##

\###

## 二、有序、无序列表和任务列表

### 1、无序列表

（ -/+/* +空格 ）

- 第一项任务
- 第二项任务
- 第三项任务

### 2、有序列表

（ N.+空格 ）

1. 第一项任务
   1. 次一级任务
2. 第二项任务
3. 第三项任务

### 3、任务列表

（ - [ ] ）

- [ ] 第一项任务
- [ ] 第二项任务
- [ ] 第三项任务

## 三、代码块

（ \`\`\`+代码类型 ）

```c
#include <stdio.h>

int main()
{
    printf("hello_world!");
    return 0;

```

（ 单\` ）

调用`equal()`函数

## 四、引用文本

（ > ）

> Markdown是一种轻量级标记语言，排版语法简洁，让人们更多地关注内容本身而非排版。它使用易读易写的纯文本格式编写文档，可与HTML混编，可导出 HTML、PDF 以及本身的 .md 格式的文件。因简洁、高效、易读、易写，Markdown被大量使用，如Github、Wikipedia、简书等。

| :--------------------------: | :--------------------: | :--------------------------: | :------------------------: |
|      **==Ctrl==+==D==**      |     **选中当前词**     |      **==Ctrl==+==L==**      |     **选中当前句/行**      |

|      **==Ctrl==+==B==**      |    **加粗当前选中**    |      **==Ctrl==+==H==**      |      **替换当前选中**      |
