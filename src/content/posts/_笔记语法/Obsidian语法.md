# Markdown基础语法

## 1.**标题**

```
# 文本内容
```

####### 最多六级标题

## 2.**段落**

```
单回车换行
双回车段落
```
多次回车仍为一个段落

## 3.**序号**

```
- 文本内容
```

## 4.**加粗**

```
**文本内容**
```

## 5. **斜体**

```
*文本内容*
```

## 6. 删除线

```
~~文本内容~~
```

## 7. 引用

```
>文本内容
```
多段落引用，每一行都需>
```
>文本内容
>文本内容
```

```
>文本内容
>>文本内容
```

## 8. 注释

```
%%文本内容%%
```

# 嵌入语法

## 1.图片

```
![图片名称](图片地址)
```

## 2.链接

```
[链接名称](链接地址) or 直接输入链接地址
```

# 代码

表示单词或者短语为代码
```
`代码内容`
```
若表示为代码的单词或短语中包含一个或多个反引号
```
``代码内容``
```
代码块
```
\```
代码内容
\```
```

# 脚注

```
[^脚注代号]
```

```
[^脚注代号]: 脚注内容

	多行脚注内容
```

# 分割

```
***
---(必须与文本空一行，否则识别为标题)
___
```

# callout语法

```
>[!规定的标记] 文本内容
>与引用的相同语法
```

规定的标记：
>[!note] note

>[!abstract] abstract,summary,tldr

>[!info] info,todo

>[!tip] tip,hint,important

>[!success] success,check,done

>[!question] question,help,faq

>[!warning] warning,caution,attention

>[!failure] failure,fail,missing

>[!danger] danger,error

>[!bug] bug

>[!example] example

>[!quote] quote,cite

***

直接显示标题
>[!note]  
>文本内容

***

折叠提示框（ + 和 - ）  
+默认展开，-默认折叠
>[!note]-  
>文本内容

***

多层级嵌套（>>>）
>[!note]
>>嵌套内容

# YAML语法

*写在正文第一行*

示范
```
---
key: value
key1: [one,two,three]
key2:
    - four
    - five
    - six
---
```

Obsidian支持的4个原生键名：
- tags：识别为标签
- aliases：识别为别名
- cssclass：识别为css片段使用
- publish：发布功能

**基本**
- uid：{{date:YYYYMMDDHHmmss}}唯一识别码，通过时间戳
- title：{{title}}文件名
- aliases：[ ]别名，以待检索
- date：{{date:YYYY-MM-DD}}创建日期
- mdate：{{date:YYYY-MM-DD}}修改日期
- tags：标签 ==本库的标签规则==

**额外**
- cover：图片封面
- weeks：日记中用于显示星期
- cssclasses：调取特定的css

**插件**
- excaildraw-plugin：绘图插件的识别
- sr-due/ease/interval：间隔复习插件的数据识别

# 日期时间格式

**年份（Year）**
- y/Y：直接表示，显示为 ==2025==
- YY/GG：简单表示，显示为 ==25==
- YYYY/GGGG：全称表示，显示为 ==2025==

**季度（Quarter）**
- Q：简单表示，显示为 ==1==
- Qo：次序显示，显示为 ==1== / ==1st==

**月份（Month）**
- M：简单表示，显示 ==2==
- Mo：次序表示，显示为 ==2== / ==2nd==
- MM：两位简单表示，显示为 ==02==
- MMM：简称表示，显示为 ==2月==/ ==Feb==
- MMMM：全称表示，显示为 ==二月==/ ==February==

**周数（Week）**
- w/W：简单表示：显示为 ==8==
- wo/Wo：次序表示，显示为 ==8周== / ==8th==
- ww/WW：两位简单表示，显示为 ==08==

**天数（Day）**

月的天数
- D：简单表示为几号，显示为 ==7==
- Do：次序表示，显示为 ==7日== / ==7th==
- DD：两位简单表示，显示为 ==07==

年的天数
- DDD：简单表示为今年的多少天，显示为 ==280==
- DDDo：次序表示，显示为 ==280日== / ==280th==
- DDDD：三位简单表示，显示为 ==280==，不足三位补零显示，如为 ==001==

周的天数
- d：简单表示，显示为 ==6==，星期天为 ==0==
- do：次序表示，显示为 ==6日== / ==6th==
- dd：简化表示，显示为 ==六== / ==Sa==
- ddd：简称表示，显示为 ==周六== / ==Sat==
- dddd：全称表示，显示为 ==星期六== / ==Saturday==

**时辰（AM/PM）**
- A：大写表示，显示为 ==下午== / ==PM==
- a：小写表示，显示为 ==下午== / ==pm==

**小时（Hour）**

24小时制
- k/H：简单表示，显示为 ==14==
- kk/HH：两位表，显示为 ==14==

12小时制
- h：极简表示，显示为 ==2==（下午两点）
- hh：两位表示，显示为 ==02==（下午两点）

**分钟（Minute）**
- m：简单表示，显示为 ==7==
- mm：两位表示，显示为 ==07==

**秒数（Second）**
- s：简单表示，显示为 ==5==
- ss：两位表示，显示为 ==05==
- S：毫秒数，显示为 ==2==
- SS：毫秒数，显示为 ==26==
- SSS：毫秒数，显示为 ==264==

**时区（Time Zone）
- Z：时间格式，显示为 ==+08:00==
- ZZ：数字格式，显示为 ==+0800==

固定内容
- 以==[ ]==包裹的内容固定显示
